# Scarf Chair — Yao Wang

Source: https://yaowang.cargo.site/Scarf-Chair  
Backed up: 2026-11-12

## Text

Scarf Chair 

 Date: Fall,2022 
 Material: steel tube, non-woven fabric, Velcro 

 The free-form scarf can be rolled and used as a neck cushion. 

 Use Velcro and attach the scarf to store magazines. 

 Can also be used as warm scarf while sitting!
